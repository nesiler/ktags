# Architecture decision records

One file per accepted decision, `NNNN-short-title.md`, MADR-style: Context, Decision,
Consequences, Alternatives considered. Accepted ADRs are immutable; a later ADR supersedes and
links back. Decisions still open are `type:decision` issues, not ADR drafts.

The decisions listed in `docs/STATUS.md` are the backlog for ADR-0001 onwards.
